Background signed staging, persistent metadata, safe-quit activation and feed rechecks are implemented with adapter/core tests; run the packaged Mac transition, complete native diagnostics runtime proof, and write installation/rollback guides.
7. **End-to-end proof — TODO:** exercise packaged N→N+1, failures/recovery/block/catch-up, AUR package lifecycle and external-device rehearsals; report remaining blockers.
