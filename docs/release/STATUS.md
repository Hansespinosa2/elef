- **Pages:** the required latest-feed URL returned HTTP 404 and `origin` has no `gh-pages` branch. **BLOCKED_EXTERNAL:** GitHub Pages must be enabled for this repository before safe-feed publication can be demonstrated. No alternate host will be used.
- **Physical Mac:** this session runs on Omarchy Linux x86-64, not Apple Silicon macOS. **BLOCKED_EXTERNAL:** Gate B Mac install/update/rollback needs an actual Apple Silicon Mac. Hosted ARM64 CI can satisfy Gate A only.
- **Local checks:** locked `npm ci` ran at the repository root and `desktop/frontend`. Profile builds, 408 Rails JavaScript tests, 26 desktop frontend tests, 21 release-ledger/Pages/reconciliation/API tests, 10 desktop E2E unit tests, 45 Rust core tests (including four diagnostics privacy/rotation tests), profile/fixture/CI contract checks, architecture/ownership checks, Rust Stable/Dev/WebDriver compile checks, and formatting passed; see the change log for exact commands and tiers. This local session uses Node 26; hosted CI on its pinned Node 22 remains necessary.
- **Observed implementation:** Stable retains Tauri ID `com.elef.desktop` and its app-data `library-root.json`; Dev now has a separate identifier and no bundle. Stable excludes experimental controllers and the graph command; Dev opts in from the repository. Linux Stable and Dev bundles exclude updater/process JS modules and native installer permissions; the updater JS adapter is selected only for Stable macOS, whose native capability is platform-limited. The deterministic release-ledger model, same-snapshot Pages projection, and mocked GitHub main-history/approval/exact-SHA reconciliation are implemented. No remote publishing workflow or Pages ledger commit exists yet. A local allowlisted diagnostics writer/exporter and Help menu entry are implemented with redaction and bounded-rotation tests; native UI and packaged verification remain. Stable configuration now names the required Pages safe-feed URL, but Pages is still unavailable and the macOS update flow still prompts for installation. No public release evidence exists.
